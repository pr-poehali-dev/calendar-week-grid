# 📅 Календарь - Умный планировщик событий

Современный веб-календарь с поддержкой мобильных устройств, drag & drop, повторяющихся событий и системой заметок.

## ✨ Основные возможности

### Календарь
- 📱 **Адаптивный дизайн** - мобильная (неделя) и десктопная (месяц) версии
- 🎨 **Цветовое кодирование** - 5 цветов для категоризации событий
- 🔄 **Повторяющиеся события** - еженедельные и ежемесячные повторы
- 🖱️ **Drag & Drop** - перетаскивание событий между датами
- 📌 **Закрепление на весь день** - события на весь день выделяются фоном
- 💾 **Автосохранение** - все изменения сохраняются мгновенно

### Заметки
- 📝 **Множественные заметки** - создавайте разные темы заметок
- 🔍 **Быстрый поиск** - легко находите нужную заметку
- 💾 **Локальное хранение** - все данные в вашем браузере
- ⚡ **Автосохранение** - изменения сохраняются с задержкой 500мс

### Управление
- ⌨️ **Горячие клавиши** - быстрое управление с клавиатуры
- 👆 **Свайпы** - листайте недели жестами на мобильном
- 🖱️ **Колесико мыши** - переключайте месяцы на десктопе
- 📤 **Экспорт** - выгрузка событий в JSON

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+N` | Создать новое событие |
| `Escape` | Закрыть все диалоги |
| `T` | Перейти к сегодняшнему дню |
| `←` | Предыдущая неделя |
| `→` | Следующая неделя |

## 🛠️ Технологии

- **Frontend**: React 18 + TypeScript + Vite
- **Стили**: Tailwind CSS
- **Компоненты**: shadcn/ui + Radix UI
- **Иконки**: Lucide React
- **Сборка**: Vite + SWC (быстрая компиляция)
- **Хранение**: localStorage + Backend API

## 🚀 Производительность

- ✅ **Обработка ошибок** - ErrorBoundary для стабильности
- ✅ **Безопасный localStorage** - защита от ошибок в приватном режиме
- ✅ **Debounce** - оптимизация частых сохранений
- ✅ **Мемоизация** - useMemo и useCallback где нужно
- ✅ **Lazy loading** - диалоги загружаются по требованию
- ✅ **Кеширование** - QueryClient с 5-минутным кешем
