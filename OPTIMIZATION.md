## Утилиты

### safeLocalStorage (`src/utils/localStorage.ts`)
Безопасная обёртка над localStorage API:
- `getItem(key)` - чтение строки
- `setItem(key, value)` - запись строки
- `getJSON<T>(key, defaultValue)` - чтение и парсинг JSON
- `setJSON<T>(key, value)` - сериализация и запись JSON
- `removeItem(key)` - удаление ключа

### debounce (`src/utils/debounce.ts`)
Функция для отложенного вызова (используется для автосохранения).

### ErrorBoundary (`src/utils/errorBoundary.tsx`)
React компонент для отлова ошибок в дереве компонентов.

### performance (`src/utils/performance.ts`)
Утилиты для измерения производительности (только в dev режиме).
