# История изменений

## [Текущая версия] - 2025-11-13

### ✅ Добавлено

#### Оптимизация и надёжность
- **ErrorBoundary** - отлов и обработка критических ошибок React
- **SafeLocalStorage** - безопасная работа с localStorage с обработкой ошибок
- **Debounce** - отложенное сохранение заметок для оптимизации
- **QueryClient оптимизация** - кеширование 5 минут, retry=1
- **Ленивая инициализация** - useState(() => ...) для localStorage операций

#### Новые возможности
- **Система заметок** - создание множественных заметок с темами
- **Горячие клавиши**:
  - `Ctrl+N` - создать новое событие
  - `Escape` - закрыть все диалоги
  - `T` - перейти к сегодня
  - `←/→` - навигация по неделям
- **Управление колесиком мыши** - переключение месяцев в ПК версии

#### UI/UX улучшения
- Равномерное распределение иконок в мобильной версии
- Белый цвет для дней недели с увеличенным размером
- Менее насыщенный красный для воскресений
- Удалены стрелки листания в мобильной версии (свайпы)

#### Документация
- `OPTIMIZATION.md` - описание всех оптимизаций
- `IMPROVEMENTS.md` - план дальнейших улучшений
- `CHANGELOG.md` - история изменений

### 🔧 Технические изменения
- Добавлена обработка ошибок во всех критических местах
- Улучшена типизация и структура кода
- Оптимизирована работа с localStorage
- Добавлены утилиты для производительности

### 🐛 Исправлено
- Потенциальные ошибки при работе с localStorage в приватном режиме
- Проблемы с производительностью при частом сохранении заметок
